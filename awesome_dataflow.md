# Awesome DataFlow 🚀

A curated list of **awesome projects, research works, and applications**
built with or on top of **[DataFlow](https://github.com/OpenDCAI/DataFlow)** — an LLM-driven framework for data preparation, synthesis, evaluation, and workflow automation in the era of **Data-Centric AI**.



---

## 📦 Open-source Projects

> Full repositories that **directly use DataFlow** as a core dependency.

- **[dataflow-speech-quality](https://github.com/chinaunicom-software-research/dataflow-speech-quality)**  
  A DataFlow Extension for speech transcript quality filtering, cleaning, de-identification, and annotation in customer-service scenarios, provided by **Jiapeng Mi** from **China Unicom Software Research Institute**.

---



### How to contribute

1. Fork this repository
2. Add your project to the appropriate section
3. Keep descriptions concise (1–2 lines)
4. Submit a Pull Request

### Contribution guidelines

- The project must **use DataFlow** (core framework or ecosystem)
- Open-source repositories are preferred
- Avoid promotional or closed-source-only entries
- Keep descriptions objective and factual
